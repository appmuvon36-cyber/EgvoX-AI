# EgvoX Official Brand & Logo Usage

## Official artwork

The existing repository asset `public/assets/aistudio/EgvoX_Official_Logo_ef943c39.webp` is used as the official full wordmark. The filename is hashed but the file is already present in the repository. Do not redraw, recolor, crop, distort, rotate, add effects to, or change the geometry of the official artwork.

The existing `public/icon.svg` is the approved compact brand mark used for symbol-only contexts and PWA icon metadata. It is the existing icon artwork, not a newly generated logo.

## Approved usage in the current asset set

- Full wordmark: `<EgvoXLogo variant="full" />`.
- Compact symbol: `<EgvoXLogo variant="symbol" />`.
- Preserve aspect ratio and use a white/neutral clear surface behind the supplied artwork where needed.
- Keep sufficient whitespace and never squeeze the wordmark into a narrow navigation slot.
- Use the full wordmark for public brand identification; use the compact mark only where space is constrained and context already identifies EgvoX.

## Brand colors

- Teal 700: `#027F86`
- Teal 600: `#039998`
- Teal 500: `#04B8B4`
- Teal 300: `#55B6B4`
- Orange 600: `#FC840E`
- Yellow 500: `#FDBA27`

Teal is the primary interaction color. Orange/yellow are supporting accent colors and must not replace semantic warning/error colors.

## Artwork limitations / variants

The repository currently contains one official full wordmark artwork and one compact `icon.svg` mark. No separately supplied monochrome-dark, monochrome-white or high-contrast logo master files were found. Those variants are therefore **not fabricated** in Phase 01. If official vector/source artwork is supplied later, variants can be exported without altering geometry or brand color rules.
